System Topology

1. Core

input schema  = event input data
rule schema   = trigger + feature + output data
output schema = event output data

An event is a channel name, not a data root. The event executor reads input data, applies rule data, and emits only output data admitted by the official output schema.

2. Data Map

3. Forbidden Roots

central feature registry schema root
central feature config schema root
event meta schema root
gap schema root
error schema root
compiler report schema root
trace / explain / diagnostic schema root

These are not primary data objects in the topology. They must be represented by event rule data, log data, control data, module-local code, or not represented at all.

4. Event Transition

official input data
  -> event executor
       reads rule data
       checks trigger path values
       runs admitted feature modules
       writes legal output data
  -> official output data | null

Rule schema is the contract for event triggers. It is not a central feature registry and not a copy of the input schema.

5. Compiler Topology

user requirement data
  -> compiler runtime
  -> rule data
  -> compiler observations written as log data

If the compiler cannot produce rule data, it writes a log record such as compile.gap and exits non-zero. It does not create a separate gap data root.
