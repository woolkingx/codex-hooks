Config

1. Stack Position

data plane      official input --(event rule schema)--> official output
control plane   config selects source paths and runtime mode at boot

Config selects policy sources, schema mirror, profile, log path, and runtime mode. It writes nothing during a hook invocation. Compiler feedback is written to log data, not to a gap root.

2. Target Root Shape

config
|- profile           "local" | "project" | "global"
|- source
|   |- user_policy       path to policy/user.json
|   |- rules_root        path to runtime rule data
|   |- profile_path      path to profile json
|   `- api_schema_dir    path to Codex schema mirror
|- mode
|   |- runtime           "enforce" | "dry-run"
|   `- fail_closed       bool
|- default               key/value overrides for schema base values
`- precedence            ["global","project","local"]

3. Node Contract

nodepurposeexample
source.user_policyUser requirement source for authoring."policy/user.json"
source.rules_rootRuntime rule data root."policy/rules"
source.profile_pathProfile JSON selecting active runtime artifacts."policy/profiles/local.profile.json"
source.api_schema_dirCodex schema mirror."schema/api/openai-codex/generated"
mode.runtimeEnforce real actions or run dry."enforce"
mode.fail_closedOn errors, deny/block when the event can project it.true
defaultActive overrides for schema base values.{ "log": { "tail": 20 } }

4. Resolution Flow

authoring flow:
read config
  -> resolve absolute source paths
  -> load user requirements / rule files
  -> boot event schema transitions

runtime flow:
read config
  -> resolve rules_root, profile_path, api_schema_dir, log path, mode
  -> load profile + rule files
  -> boot event handlers

5. Default Rule

schema.default = base value supplied by schema2object
config.default = active runtime override
runtime_value  = config.default ?? schema.default ?? input

Rule files are pure data and never read config directly.

7. Source Roles

policy/user.json is authoring input. policy/rules/ is runtime rule data. Config may point both paths elsewhere, but it must not create another policy source shape.
