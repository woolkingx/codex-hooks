block-first-time proof contract

The feature proves first-time matching only when a status-owned hook-state ledger is provided.

  • With hook-state context, evaluation returns true only for the first `cwd + session_id + compact_mark + key` observation.
  • Commit writes to status-owned hook-state only after the rule output validates.
  • Without hook-state context, evaluation returns false and commit is a no-op.
